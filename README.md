# J-CRAFT

Открытый трёхмерный мир для прогулок, строительства и программирования на блоках и Python. Можно играть одному или подключиться к миру учителя по локальной сети.

**Скачать J-CRAFT 0.17.18 — настройки учителя и мост агента**

- [Mac с Apple Silicon (M1 и новее)](https://github.com/user116RUS/J-CRAFT/releases/download/v0.17.18/J-CRAFT-0.17.18-Mac-arm64.zip) — распакуйте ZIP и откройте J-CRAFT.app.
- [Windows 10/11 x64](https://github.com/user116RUS/J-CRAFT/releases/download/v0.17.18/J-CRAFT-0.17.18-Windows.zip) — извлеките весь архив и откройте J-CRAFT.exe внутри папки J-CRAFT.

Первые два квестовых персонажа находятся примерно в 300 блоках друг от друга. Третий — Хранитель огненной переправы — расположен ещё в 1000 блоках по горизонтали от второго. После двух квестов переход `/lava` ведёт к заданию: построить мост агентом через обычный Code Builder, перейти по нему и вернуться за ключом. Ручной мост не засчитывается; личный прогресс сохраняется. Продолжение с использованием ключа пока не добавлено.

Перед запуском мира учитель выбирает параметры сервера. В игре `/server` позволяет менять время суток и управлять занятием.

Проверено на одном Mac; физический Windows и класс по LAN с этой версией не проверены. Причина длительных задержек bridge и общих отключений класса остаётся открытой.

**Обновить класс.** С версии 0.17.9 закройте игру и в главном окне нажмите «Проверить обновления / обновить класс». Учитель может скачать пакет для Mac или Windows и раздать его ученикам по локальной сети. На компьютерах учеников выберите «Получить обновление от учителя». Для первого перехода с 0.17.8 распакуйте ZIP вручную. [Инструкция для учителя](UPDATES.md).

Для прогулки выберите «Играть одному». W/A/S/D — ходьба, мышь — обзор, пробел — прыжок. Введите /code в игровом чате, чтобы открыть редактор.

[Все выпуски и контрольные суммы](https://github.com/user116RUS/J-CRAFT/releases)
