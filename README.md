# J-CRAFT

Открытый трёхмерный мир для прогулок, строительства и программирования на блоках и Python. Можно играть одному или подключиться к миру учителя по локальной сети.

**Скачать J-CRAFT 0.17.16 — устойчивость связи класса**

- [Mac с Apple Silicon (M1 и новее)](https://github.com/user116RUS/J-CRAFT/releases/download/v0.17.16/J-CRAFT-0.17.16-Mac-arm64.zip) — распакуйте ZIP и откройте J-CRAFT.app.
- [Windows 10/11 x64](https://github.com/user116RUS/J-CRAFT/releases/download/v0.17.16/J-CRAFT-0.17.16-Windows.zip) — извлеките весь архив и откройте J-CRAFT.exe внутри папки J-CRAFT.

Квестовые персонажи стоят на суше примерно в 300 блоках друг от друга. После выбора задания открывается Code Builder; личный прогресс сохраняется.

**Обновить класс.** С версии 0.17.9 закройте игру и в главном окне нажмите «Проверить обновления / обновить класс». Учитель может скачать пакет для Mac или Windows и раздать его ученикам по локальной сети. На компьютерах учеников выберите «Получить обновление от учителя». Для первого перехода с 0.17.8 распакуйте ZIP вручную. [Инструкция для учителя](UPDATES.md).

Для прогулки выберите «Играть одному». W/A/S/D — ходьба, мышь — обзор, пробел — прыжок. Введите /code в игровом чате, чтобы открыть редактор.

[Все выпуски и контрольные суммы](https://github.com/user116RUS/J-CRAFT/releases)

Игра использует движок Luanti и мир VoxeLibre. Автор набора [REFI Textures](https://content.luanti.org/packages/MysticTempest/refi_textures/) — MysticTempest (CC BY-SA 4.0). Лицензии компонентов включены в архивы. J-CRAFT — самостоятельный проект.
