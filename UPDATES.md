# Обновления J-CRAFT

В версии 0.17.9 и новее закройте игру или завершите занятие. В главном окне нажмите **«Проверить обновления / обновить класс»**. На своём компьютере выберите «Проверить обновления на GitHub», подтвердите новую версию и после закрытия приложения откройте прежний ярлык. Проверка выполняется по запросу. Доступ к интернету для обычной игры не требуется.

## Раздача с компьютера учителя

Выберите **операционную систему учеников** и «Скачать и раздать классу». Например, учитель на Mac может раздать Windows-архив. На ученических компьютерах выберите «Получить обновление от учителя» и подтвердите установку. Если поиск ничего не нашёл, введите IPv4 учителя. Держите окно раздачи открытым, пока все компьютеры не закончат загрузку. Повторить раздачу можно без интернета кнопкой «Раздать ранее скачанный пакет без интернета». Для смешанного класса проведите две раздачи по очереди.

Для первого перехода с 0.17.8 учитель устанавливает ZIP вручную. На старых ученических компьютерах можно скачать ZIP через браузер по адресу из окна раздачи учителя, распаковать и запустить. Школьная сеть должна разрешать соединения учеников с учителем по TCP 38767. Автопоиск использует UDP 38767. При недоступности раздачи остаётся [страница последнего выпуска на GitHub](https://github.com/user116RUS/J-CRAFT/releases/latest).
